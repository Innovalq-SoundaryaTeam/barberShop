# The Barber Studio

A premium responsive barbershop and men's grooming website template developed using HTML5, CSS3, JavaScript, and Bootstrap 5.

---

## Features

- Responsive Design
- Dark and Light Mode
- RTL Support
- Service Pages
- Gallery
- Pricing Section
- Blog Pages
- Contact Page
- 404 Page
- Coming Soon Page
- SEO Friendly
- Easy Customization

pages/index.html

with Live Server.
